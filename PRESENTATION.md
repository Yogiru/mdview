# MdView 1.1

## Лёгкий просмотрщик документов для Windows

> Один exe-файл. Ноль зависимостей. Мгновенный запуск.

---

## Что такое MdView

MdView — минималистичный просмотрщик документов в разметке.
Никаких Electron, WebView и внешних библиотек — чистый нативный код
на Free Pascal с собственным движком рендеринга **Pixie**.

- Размер: ≈1 МБ — один exe-файл
- Запуск: мгновенный
- Установка: не требуется (портативный)
- Права: администратор не нужен

---

## Форматы

| Формат | Расширения | Для чего |
| --- | --- | --- |
| **Markdown** | .md .markdown .mdown .mdwn .mkd .txt | заметки, README, документация |
| **SVG** | .svg | векторная графика |
| **FictionBook** | .fb2 .fbz .fb2z .zfb2 | электронные книги |
| **CHM** | .chm | скомпилированная справка |

Всё — одним файлом, без кодеков и библиотек.

---

## Markdown

Полный набор: заголовки, списки, task-листы, таблицы, цитаты,
блоки кода с подсветкой, изображения, ссылки, якоря.

Оглавление строится автоматически по заголовкам H1–H6 —
панель слева, клик → переход к разделу.

---

## SVG

Файл `.svg` открывается как документ — векторный рендер
встроен в движок. Иконки, схемы, диаграммы — просто бросьте
файл на окно.

---

## FB2 / FBZ

Книги FictionBook: титул, авторы, секции, эпиграфы, стихи,
цитаты и иллюстрации из `<binary>` — всё на месте.

Сжатые варианты (.fbz, .fb2z, .zfb2) распаковываются на лету.

---

## CHM

Классическая справка Windows: страницы, картинки, внутренние
ссылки — и полное дерево документации в панели Outline.

Кодировки CP1251/KOI8-R/UTF-8 распознаются автоматически.

---

## Рабочее место читателя

- **Ctrl+F** — поиск с подсветкой всех вхождений
- **F9** — оглавление; **F8** — тёмная тема; **F11** — поверх окон
- **Alt+←/→** — история; **[ ]** — соседние файлы в папке
- Drag&drop, командная строка, авто-перечитывание файла
- Сохранение в HTML и печать

---

## Ассоциации — без батников

Меню **⋯ → File associations…**: список расширений с чекбоксами,
статус каждого, регистрация/снятие в один клик.

Всё в HKCU — админ не нужен. `SHChangeNotify` — Explorer
подхватывает иконки сразу.

---

## DPI

Манифест **PerMonitorV2**: корректный рендер на 125%/150%/200%
и при переносе окна между мониторами с разным масштабом.

Все размеры интерфейса масштабируются по текущему DPI окна.

---

## Под капотом

- Free Pascal 3.2.2 / Lazarus LCL, Win32
- Движок Pixie: HTML/CSS/Markdown/SVG на чистом Pascal
- CHM — штатный пакет FPC (chmreader + LZX-декомпрессор)
- FB2 — собственный трансформер XML → HTML (FPC DOM/XMLRead)
- Одно окно — один процесс: single-instance через WM_COPYDATA
