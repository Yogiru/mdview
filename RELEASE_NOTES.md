# MdView 1.1 — Release Notes

## Новые форматы

- **SVG** — векторная графика, встроенный рендер Pixie.
- **FB2 / FBZ / FB2Z / ZFB2** — книги FictionBook: титул, авторы, секции,
  стихи, цитаты, иллюстрации из `<binary>`; zip-варианты распаковываются.
- **CHM** — скомпилированная справка: страницы, ресурсы, внутренние
  ссылки; оглавление файла переходит в панель Outline; авто-декод
  UTF-8/CP1251/KOI8-R.

Ноль новых зависимостей: всё реализовано штатными средствами
FPC (DOM/XMLRead, zipper, пакет chm) и движком Pixie.

## Форма ассоциаций файлов

Меню `⋯` → **File associations…** — регистрация/снятие ассоциаций
прямо из программы: список 11 расширений с чекбоксами и текущим
статусом, кнопки Выбрать все / Снять выбор / Зарегистрировать /
Убрать ассоциацию / Настройки Windows. Всё в HKCU, админ не нужен.
Внешние SFTA.ps1/SetDefaultMdView.ps1 больше не используются.

## DPI

Per-Monitor V2 в манифесте; обработка WM_DPICHANGED; все размеры
интерфейса масштабируются по DPI окна (MulDiv).

## Исправления

- Якорные ссылки `#заголовок` (включая кириллические) — клики по
  ссылкам теперь обрабатываются через OnElementClick (OnAnchorClick
  в Pixie не вызывается), фрагмент URL-декодируется, поиск по
  slug-тексту заголовка.
- Drag&drop: ранее написанный, но не подключённый FileDropTarget
  подключён — OLE-drop ловится и на области документа.
- Битый .fbz раньше мог уронить приложение (EZipError) — теперь
  диалог ошибки.
- Аудит: удалены заглушки, дубли и мёртвый код (~200 строк),
  включая старый код ассоциаций через PowerShell.

## Известные ограничения

- Поиск по CHM — в пределах текущей страницы.
- Ссылки `javascript:` внутри CHM не выполняются.
- `.fb2.gz` (gzip) не поддерживается.
