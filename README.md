## Поддерживаемые форматы

| Формат | Расширения | Примечание |
| --- | --- | --- |
| Markdown | `.md`, `.markdown`, `.mdown`, `.mdwn`, `.mkd`, `.txt` | основной формат |
| SVG | `.svg` | векторная графика, рендерится движком Pixie |
| FictionBook | `.fb2`, `.fbz`, `.fb2z`, `.zfb2` | электронные книги, картинки из `<binary>` |
| CHM | `.chm` | Compiled HTML Help, оглавление переходит в панель Outline |

Всё открывается одним исполняемым файлом — **никаких внешних библиотек и кодеков**.

---

## Возможности

- Открывает файлы `.md`, `.markdown`, `.mdown`, `.mdwn`, `.mkd`, `.txt`, `.svg`, `.fb2`, `.fbz`, `.fb2z`, `.zfb2` и `.chm`.
- Автоматически перезагружает файл при изменении на диске.
- Показывает оглавление по заголовкам `H1..H6` (для CHM — по дереву документации).
- Переключается между светлой и тёмной темой.
- Держит окно поверх всех окон (Always on top / float-режим).
- Ищет по тексту с подсветкой найденных вхождений.
- Поддерживает внутренние и внешние ссылки: `http/https/mailto` открываются в браузере, локальные `.md` — в MdView, якоря `#заголовок` — прокручиваются (включая кириллические якоря).
- Переключается между соседними Markdown-файлами в папке.
- Сохраняет документ как HTML и отправляет на печать.
- Перетаскивание файлов на окно (OLE drag&drop + проводник).
- **Per-Monitor DPI-aware (V2)**: корректное масштабирование на мониторах 125%/150%/200% и при переносе окна между экранами.
- Встроенная форма ассоциаций файлов: выбор расширений, регистрация и снятие прямо из программы, без внешних скриптов.
- Автоматически определяет и вручную переключает кодировку: UTF-8 (с/без BOM), UTF-16 LE/BE, Windows-1251.
- Работает без установки: настройки хранятся в `mdview.ini` рядом с `mdview.exe`.

## Системные требования

- Windows XP / 7 / 8.1 / 10 / 11 (x86/x64). 
- Никаких сторонних библиотек для запуска готового `mdview.exe` не требуется.

## Установка и запуск

### Портативная версия

1. Скачайте [mdview-portable-1.1.zip](https://github.com/Yogiru/mdview/raw/main/mdview-portable-1.1.zip).
2. Распакуйте в любую папку.
3. Запустите `mdview.exe`.

Все настройки и список недавних файлов сохраняются рядом с `mdview.exe`.

### Ассоциации файлов

Установщик больше не нужен: ассоциации настраиваются прямо в программе —
меню `...` → **File associations…** (см. раздел [Ассоциация файлов](#ассоциация-файлов)).
Всё записывается в `HKEY_CURRENT_USER`, прав администратора не требуется.

## Как открыть файл

- Кнопка `+` в правом верхнем углу окна или `Ctrl+O`.
- Двойной клик по поддерживаемому файлу в Проводнике (если назначена ассоциация).
- Перетаскивание файла на окно MdView.
- Командная строка: `mdview.exe путь\к\файлу.md`.
- При первом запуске, если есть недавние файлы, появляется диалог **Recent files**.

## Интерфейс

Окно состоит из:

- **Панели просмотра** (`ViewPanel`) — основная область с отрендеренным документом.
- **Оглавления** (`Outline`) слева — дерево заголовков `H1..H6` (для CHM — структура документации).
- **Плавающей панели управления** в правом верхнем углу:
  - `+` — открыть файл.
  - `<` / `>` — показать/скрыть оглавление.
  - `D` / `L` — тёмная/светлая тема.
  - `^` — поверх всех окон.
  - `...` — дополнительное меню (недавние файлы, ассоциации).
  - `100%` — текущий масштаб; клик сбрасывает к 100%.
- **Строки поиска** в левом верхнем углу (появляется по `Ctrl+F` или `F3`).

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl+O` | Открыть файл |
| `Ctrl+R` | Перечитать текущий файл |
| `Ctrl+F` / `F3` | Открыть панель поиска / найти следующее |
| `Shift+F3` | Найти предыдущее вхождение |
| `Esc` | Закрыть панель поиска |
| `F5` | Перезагрузить файл с диска |
| `Ctrl+D` / `F8` | Переключить светлую/тёмную тему |
| `F9` | Показать/скрыть оглавление |
| `F11` | Поверх всех окон (Always on top) |
| `Ctrl+Shift+P` | То же — поверх всех окон |
| `Ctrl+\` | Показать/скрыть оглавление |
| `Ctrl++` / `Ctrl+-` | Увеличить/уменьшить масштаб |
| `Ctrl+0` | Сбросить масштаб к 100% |
| `Alt+←` / `Alt+→` | Назад / вперёд по истории |
| `[` / `]` | Предыдущий / следующий Markdown-файл в папке |
| `Ctrl+P` | Печать |
| `Ctrl+Shift+S` | Сохранить как HTML |
| `Ctrl+C` | Копировать выделенный текст |

В строке поиска:

| Клавиша | Действие |
| --- | --- |
| `Enter` | Следующее вхождение |
| `Shift+Enter` | Предыдущее вхождение |
| `F3` | Следующее |
| `Shift+F3` | Предыдущее |
| `Esc` | Закрыть поиск |

Дополнительно мышью: боковые кнопки (`X1` / `X2`) работают как "назад" и "вперёд" по истории.

## Командная строка

```text
mdview.exe [опции] [файл]
```

| Опция | Смысл |
| --- | --- |
| `файл` | Открыть файл любого поддерживаемого формата (можно без `--`) |
| `--float`, `/float`, `--pin`, `--topmost` | Окно поверх всех окон |
| `--no-float`, `--dock` | Обычное окно |
| `--dark`, `/dark` | Тёмная тема |
| `--light`, `/light` | Светлая тема |
| `--outline`, `--toc` | Показать оглавление |
| `--no-outline`, `--notoc` | Скрыть оглавление |
| `--zoom=150` | Масштаб в процентах, диапазон `25..400` (можно `--zoom 150`) |
| `--help`, `/?`, `-h` | Справка |

Примеры:

```text
mdview.exe readme.md
mdview.exe book.fb2
mdview.exe --float --dark D:\notes\todo.md
mdview.exe /float /dark /zoom=125 notes.md
```

Программа работает в единственном экземпляре: второй запуск передаёт файл уже открытому окну.

## Контекстное меню

Правый клик по тексту открывает меню:

- **Copy** — копировать выделенный текст.
- **Copy path** — копировать полный путь к файлу.
- **Copy file name** — копировать имя файла.
- **Show in Explorer** — открыть папку файла.
- **Copy code block** — скопировать содержимое текущего блока кода.
- **Find…** — открыть поиск.
- **Back / Forward** — навигация по истории.
- **Previous file / Next file** — соседние Markdown-файлы.
- **Encoding: UTF-8 / Encoding: Windows-1251** — принудительно перечитать файл в выбранной кодировке.
- **Save as HTML…** — сохранить отрендеренный документ в HTML.
- **Print…** — отправить на печать.

## Ассоциация файлов

Управление ассоциациями встроено в программу — внешние скрипты не нужны:

- В окне MdView: `...` → **File associations…**
- В открывшейся форме отметьте расширения, которые должен открывать MdView (Markdown, SVG, FB2, CHM), и нажмите **Зарегистрировать**.
- Для каждого расширения видно, какая программа сейчас назначена по умолчанию.
- Кнопка **Убрать ассоциацию** снимает привязку (только записи MdView — чужие настройки не трогаются).
- Кнопка **Настройки Windows…** открывает системный диалог выбора программы по умолчанию.

Ассоциации прописываются в `HKEY_CURRENT_USER`, **прав администратора не требуется**. При использовании установщика ассоциация `.md`/`.markdown` создаётся автоматически.

## Кодировки

Программа автоматически распознаёт:

- UTF-8
- UTF-8 с BOM
- UTF-16 LE / BE
- Windows-1251 (CP1251)

Если текст отображается некорректно, переключите кодировку через контекстное меню: **Encoding: UTF-8** или **Encoding: Windows-1251**.

---

## Автообновление файла

MdView раз в секунду проверяет возраст открытого файла. Если файл изменился на диске, он перечитывается автоматически — удобно при параллельном редактировании.

---

## Экспорт и печать

- **Сохранить как HTML** (`Ctrl+Shift+S`): экспортирует документ вместе со встроенным CSS.
- **Печать** (`Ctrl+P`): формирует временный HTML-файл и вызывает системный диалог печати.

---

## Настройки

Все параметры сохраняются в `mdview.ini` рядом с `mdview.exe`:

```ini
[View]
Dark=0
Outline=1
Float=0
Zoom=1

[Window]
Left=...
Top=...
Width=...
Height=...
Maximized=0

[Float]
Left=...
Top=...
Width=...
Height=...

[Recent]
Count=...
0=...
```

Для сброса настроек достаточно удалить `mdview.ini`.

## Поддерживаемый Markdown

MdView использует движок Pixie (рендер Markdown/HTML/SVG на чистом Pascal, без внешних зависимостей). Поддерживаются:

- Заголовки `H1..H6`
- Параграфы и переносы
- Жирный, курсив, зачёркнутый, маркированный текст
- Списки (упорядоченные, неупорядоченные, вложенные)
- Task-листы (`- [ ]` / `- [x]`)
- Блоки кода и инлайн-код
- Цитаты
- Горизонтальные линии
- Таблицы
- Изображения
- Ссылки, в том числе `mailto:`
- Якоря по заголовкам
